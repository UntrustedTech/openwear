# OpenWear: Android app

The Flutter app (with Kotlin platform code in `android/`). See the [main README](../README.md) for what it does and how to build it.

- `lib/protocol/`: the band's Bluetooth protocol (framing, encryption, commands)
- `lib/services/`: the band connection, sync, Health Connect, weather and export
- `lib/faces/`: the watch-face encoder and built-in designs
- `lib/ui/`: screens and the UI kit
